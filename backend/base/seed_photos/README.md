# Demo dish photos

`python manage.py seed_demo` attaches a photo to each demo menu when a file with the matching name is in this folder. Menus without a matching file simply have no photo.

- File type: `.jpg`, `.jpeg`, `.png` or `.webp`
- Shape: landscape, about 3:2, at least 1200 px wide, with the dish in the centre (cards crop the top and bottom)
- Size: under 500 KB each is ideal; the app's limit is 3 MB
- Only add images you have the right to publish

After adding files, run `python manage.py seed_demo` again. It fills in menus that have no photo yet.
